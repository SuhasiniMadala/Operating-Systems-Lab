# Operating Systems Lab

A collection of Operating Systems laboratory exercises implemented in C and Bash as part of EGC 301P at IIIT Bangalore.

## Topics Covered

* File Management
* Process Management
* Process Scheduling
* Pipes and FIFOs
* Message Queues
* Shared Memory
* Semaphores
* Socket Programming
* Signals
* Multithreading
* Resource Limits

## Technologies

* C
* Bash
* Linux System Calls
* GCC

## Repository Structure

* File Management
* Process Management
* System V IPC Mechanisms
* Timers, Signals and Threads
